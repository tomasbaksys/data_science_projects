## 🚀 Featured Projects  

### 1. [KiloHealth Colonbroom Project](KiloHealth_Colonbroom_Project)  
**Goal**: Predict customer purchase behavior (buyer/non-buyer) and upsell recommendations.  

**Tools**: Python, Pandas, Scikit-learn, Matplotlib, Seaborn, NumPy  

**Results**:  
- XGBoost achieved **90% recall** and **54% accuracy** for buyer classification.  
- **92% recall** for upsell purchase prediction.  
- Improved upsell marketing effectiveness from **36%** to **63%**.
